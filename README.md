## Гайд по приложению
# важно!
* при открытии сайта в браузере необходимо писать localhost, а не 127.0.0.1, дабы не нарушать cors
### Запуск приложения
* запуск сервера производится из корневой папки проекта с помощью sh файла ```host_backend.sh```
### ДЕПЛОЙ
- для работы приложения необходим python 3.12-3.13, после клонирования репозитория требуется скачать все библиотеки из папки зависимостей с помощью команды ```pip install -r requirements.txt```
### Структура запросов
все запросы можно посмотреть с помощью документации swagger от fastAPI командой http://localhost:8000/docs
#### Что передавать в json для запросов?
В папке ***tests*** есть примеры json-ов, в переменных data, также все запросы подробно описаны в документации
### кнопки на сайте
* для обновления карты после перерасчета необходимо обновлять сайт, кнопка для автоматической генерации инженеров не предусмотрено, их необходимо создавать вручную. датасеты можно загружать в формате csv в модальном окне, открывающемся по кнопке "планирование". Кнопки редактирования заявок и редактирования инженеров не работают. все данные о заявках и инженерах должны строго соответствовать pydantic схемам. с ними можно ознакомиться в файле data_scemas.py
