## Гайд по приложухе
### Запуск приложения
* запуск сервера производится из папки backend ```cd backend```
* чтобы запустить сервер введи в терминале ```uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload```
### Важные переменные
* В файле ***backend/main.py*** есть переменные PATH_TO_STATIC и PATH_TO_TEMPLATES, которые отвечают за путь к фронтенд фалам
### ДЕПЛОЙ
- при деплое обрать ограничения в файле csv_handler/parse.py на количество обработок(ставил чтобы эконосить запросы)
### Структура запросов
/index - главная страница

/admin - операции с бд

/api - ветка для api

/api/urgent_request - добавление срочной заявки

/api/delete_request - удаление(отмена) заявки

/api/engineer_unavailable - удаление инженера(инженер не доступен)
